# yoko-apps

「よこ」シリーズのAndroidアプリ置き場。自分の端末に直接入れて使う。

| フォルダ | 中身 | 状態 |
| --- | --- | --- |
| `pomodoro-timer/` | よこドーロタイマー（ポモドーロタイマーとウィジェット） | 動作中 |
| `news-widget/` | よこずらしニュース（日付・天気・ニュースのウィジェット） | 仕様のみ。実装はこれから |
| `step-widget/` | よこめぐり（歩いた累計の距離で日本を進む、歩数のウィジェット） | 0.21。歩数はヘルスコネクトから読む（Android 14 以上）。都道府県の標章は入れた。名物の絵はこれから |

## 共通の作り

- Java、Gradleなし。各フォルダの `build.sh`（aapt2・javac・d8）でAPKを作る
- minSdk 26、外部ライブラリなし
- ビルドの出力先 `build/` はコミットしない
- 署名は開発用の `debug.keystore`。同じ鍵で署名しないと、端末のアプリを上書き更新できない
